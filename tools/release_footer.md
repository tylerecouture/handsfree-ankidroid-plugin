### Installing

**New install:** import `AnkiVoice-test.apkg` on the phone to try it out, then
follow the [README](https://github.com/tylerecouture/handsfree-ankidroid-plugin#install)
to add the loader to your own note types.

**Updating an existing install:** download `_ankivoice.js`, overwrite the copy in
your desktop `collection.media` folder, and sync. **Do not** rely on importing
the `.apkg` to update — Anki renames a colliding media file rather than
overwriting it, so your old script keeps running and nothing tells you.

**Check which version is live:** the bar reads `AnkiVoice v<n>` before a card
starts, and the settings panel header shows it too.
